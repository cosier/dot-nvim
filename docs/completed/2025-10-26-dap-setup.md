## Key Learnings

### LazyVim Extras System

LazyVim uses an "extras" system for optional features:
- Located in `lua/lazyvim/plugins/extras/`
- Enable by importing in `lazy.lua`
- Includes pre-configured DAP, language support, etc.

**Don't create custom DAP plugin from scratch** - use LazyVim extras!

### Correct Directory Structure

```
~/.config/nvim → ~/conf/dot-nvim (symlink)

~/conf/
├── dot-nvim/           # ✅ ACTUAL config (git repo)
├── dot-nvim-lazyvim/   # Reference only (LazyVim source)
└── nvim/               # ❌ WRONG (removed)
```

Always work in `dot-nvim`, NOT `nvim`!

### Plugin Loading

LazyVim extras are:
- Lazy-loaded by default
- Installed via `:Lazy sync`
- Configured through `opts` functions in custom plugins
- Extend, don't replace, default configs
